# Big Data Analytics (W3-BDA) — HTW Berlin

Angewandter KI-Kurs im Master Wirtschaftsinformatik (HTW Berlin). Wir bauen über
das Semester **ein** KI-Produkt end-to-end: ein Werkzeug, das aus unstrukturierten
Produktbewertungen ein klares Bild macht — Sentiment, Themen, Trends,
Zusammenfassung.

Offizielles Modul: **Big Data Analytics (W3-BDA, PCÜ)**, WiSe 2026/2027.

## Wie dieses Repo funktioniert

Kein Foliensatz — der Code ist das Skript. Jede Sitzung liegt als Colab-Notebook
hier im Repo. Ablauf:

- Vor bzw. in jeder Sitzung: dieses Repo klonen oder aktualisieren (`git pull`).
- Notebooks direkt in **Google Colab** öffnen — keine lokale Installation nötig,
  alles läuft im Browser.
- Material wird **pro Sitzung nach der Veranstaltung** veröffentlicht.

```text
git clone https://github.com/kevisback/bda-course.git
```

## Aufbau

Ein durchgehendes Produkt, in fünf Phasen über 16 Sitzungen. Die jeweilige
Durchführung liegt in einem eigenen Ordner (z. B. `wise2627/`), damit die
Repo-Adresse über die Semester stabil bleibt.

```text
Phase 1  Grundlagen & Problemstellung
Phase 2  Vom Text zur Struktur
Phase 3  Vom Prototyp zur Realität
Phase 4  Vertrauen & Evaluation
Phase 5  Ausliefern (Projektarbeit + Demo Day)
```

Aktuelle Durchführung: [`wise2627/`](wise2627/).

## Prüfung

Projektarbeit (Konzept + Demo), Gruppen von 2–3 möglich. Details folgen in der
Veranstaltung und im schriftlichen Prüfungs-Briefing.
